## 三、思考題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
**答：**
測試一整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']` 共 4 筆資料，但 `'amy'` 重複出現了兩次。依規則同一人在同一場活動只算一位參加者、只收一次費用，所以實際參加桌遊的人只有 `{'amy', 'ben', 'cora'}` 共 3 人（費用為 $3 \times 120 = 360$ 元）。

- **直接拆成 `list`**：保留了原本的**填報順序**與**重複次數**，但因為有重複元素，不能直接拿長度當作實際參加人數或計費人數，也沒有固定的索引順序之外的集合比較功能。
- **轉成 `set`**：保留了**不重複的參加者成員**，方便做交集、聯集與差集比較，但失去了**重複報名的次數資訊**與**原本的排列順序**（集合本身沒有順序與索引，顯示前需要先排序）。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
**答：**
測試三中，桌遊集合與電影集合去重後都是 `{'amy', 'ben', 'cora'}`，兩者完全相同（交集與聯集都是這 3 人，差集皆為空集合 `[]`）。

- **總不重複人數**：聯集元素個數 $|A \cup B| = 3$ 人（`amy`、`ben`、`cora`）。
- **報名人次**：每位參加者都報了兩場活動，因此報名人次為兩場去重人數相加：$3 + 3 = 6$ 人次。
- **總應收計算**：桌遊收 $3 \times 120 = 360$ 元，電影收 $3 \times 80 = 240$ 元，兩場合計為 $360 + 240 = 600$ 元。雖然只有 3 位不同的人，但因為每人各參加兩場，兩場都要分別計費，所以總應收仍是 600 元。
